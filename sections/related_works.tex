\section{Related Work}
\subsection{Model Repair in Symbolic Planning}
Symbolic planners fail outright when a task is unsolvable as specified; \emph{model repair} asks how the specification can be modified so that a solution exists~\cite{bercher2025modelrepair}. A closely related line of work on \emph{creative problem solving} treats such failures as an agent's model of the world being insufficient to complete the task at hand~\cite{ijcai2023p777}. Prior work addresses these insufficiencies in several ways. Reinforcement learning has been used to learn recovery policies or action executors that return the agent to a state from which planning can resume~\cite{rapid_learn,lorang_rsj_2024, li2024learning}, as well as to improve robustness in task and motion planning under execution uncertainty~\cite{jiang2018integrating}. Other approaches discover new action primitives or learn the symbolic concepts required to integrate newly acquired skills into future plans~\cite{gizzi_ieee_2019,li2026recover}. In contrast, \citet{gragera2023repair} repair the symbolic action model directly by compiling an unsolvable task into an extended task in which missing action effects may be inserted.

% Both motivate approaches that repair the \emph{action model}. Reinforcement learning can discover new action primitives after the agent reaches an unrecoverable state~\cite{jiang2018integrating,rapid_learn,lorang_rsj_2024}; related approaches are proposed by Alicia Li et al.~\cite{li2024learning} and Bowen Li et al.~\cite{li2026recover}. \citet{gizzi_ieee_2019} instead enumerate candidate action--object combinations following a failure. In contrast, \citet{gragera2023repair} repair incomplete action effects by compiling the unsolvable task into an extended task in which the missing effects may be inserted.

% Both motivate approaches that repair the \emph{action model}: reinforcement learning discovers new action primitives after reaching an unrecoverable state~\cite{jiang2018integrating,li2024learning, li2026recover, rapid_learn, lorang_rsj_2024}, and \citet{gizzi_ieee_2019} enumerate action-object combinations following a failure case. \citet{gragera2023repair} instead fix incomplete action effects, compiling the unsolvable task into an extended task that may insert the missing effects.

These approaches expand or alter the domain's actions. Our repair is deliberately narrower: we leave the domain, goal, and initial state intact and reassign only the types of objects already present, so that a functionally appropriate object can fill a role the original typing excluded. Most relevant to our design, \citet{gragera2023exploring} prompt an LLM \emph{stand-alone} to fix unsolvable tasks and find its limited reasoning insufficient for identifying repairs that yield solvable tasks. We reach a different outcome by changing the LLM's role: rather than trusting it to repair the task, we confine it to proposing type reassignments and delegate all verification to the symbolic planner.

\subsection{LLMs for Planning}
The use of LLMs for symbolic planning has been widely explored and it often has met with
mixed results. \citet{motwani2026longcot} find that LLMs struggle with long-horizon Chain of Thought (CoT) tasks in general. LLMs plan generation benchmarks show that LLMs do not reliably produce correct plans
\citep{valmeekam_large_nodate, valmeekam2023planbenchextensiblebenchmarkevaluating}. Despite these limitations, LLMs show promise as components within larger planning pipelines rather than as end-to-end planners. \citet{liu_llmp_2023} use LLMs to generate PDDL problem files from natural language descriptions, while \citet{singh_twostep_2024} demonstrate that LLMs can decompose problems into simpler sub-tasks amenable to parallel execution. Researchers have similarly integrated LLMs into Hierarchical Task Networks to decompose high-level goals into more tractable sub-tasks \citep{pmlr-v288-munoz-avila25a, xu2025online}. LLMs have also been used to find symbolic models given pre-existing black-box style executors \cite{yang2026skillwrappergenerativepredicateinvention}.

Another line of research uses LLM-generated outputs to guide or improve
search and learning. \citet{silver2022pddl} propose treating an LLM-generated
plan, even an incorrect one, as a heuristic to guide greedy
best-first search, and \citet{hazra_saycanpay_2024} similarly incorporate heuristics to improve LLM-based planning. \citet{kambhampati_llms_2024} take a complementary
approach, employing critics to evaluate and refine plans produced by
LLMs. Researchers have also explored
using LLMs' code generation capabilities to produce programs that
solve specific tasks \citep{silver2024generalized}.

Prior research has also explored using LLMs to create symbolic representations of the world at runtime \cite{argenziano2024empowerembodiedmultiroleopenvocabulary}. Most closely related to CAST, \citet{musumeci2025context} propose using an LLM to generate and iteratively refine PDDL, combined with a symbolic planner to find suitable goal substitutions when the original goal is not reachable. In contrast, CAST preserves the original goal by using an LLM to reclassify available objects into the required types at runtime, enabling the original plan to remain valid without relaxing the task specification.
