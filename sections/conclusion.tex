\section{Conclusion}
We have presented an approach for augmenting an off-the-shelf symbolic planner with an LLM to enable creative problem solving. Using three different variations, we have demonstrated that small, single GPU open-weight LLMs can successfully make valid typing substitutions that render unsolvable problems, solvable. We compared our implementation to a pre-existing LLM based PDDL planner, and demonstrated significant performance increases across a variety of problem categories and semantic encodings.

This work is not without limitations. Namely, the presented approach offers no formal guarantees that substitutions made are valid. As an example, a \texttt{pick-up} action may only apply to certain objects, like those that are rigid, and may not be transferable to others, like deformable ones. Additionally, We rely on the assumption that the action name is semantically rich enough to describe its use. Substituting \texttt{pickup-object} with a less rich encoding like \texttt{action1} provides no semantic information on the affordances of the action and which objects it might apply to.

Future work might consider using a multiplexer of some sort to dynamically balance the trade offs of each of the proposed approaches at runtime. For example, in a situation where a substitution is likely, it would make sense to use the interactive method. Conversely, in a mission critical setting where mistakes can be costly, the trade off in refusal accuracy is not acceptable. Additional work might also consider ways to encode affordances along side of actions so that the LLM has a stronger grasp on what objects each action can be performed on.
